# 採用ダッシュボード（支援先）

採用支援クライアントの進捗を1つの画面で見る。データは会社ごとのGoogleスプレッドシートから直接読む（5分ごとに自動更新、「更新」ボタンで即時）。

## 仕組み

```
Googleスプレッドシート（会社ごとに1冊）
   ├ 応募者   … 候補者1人1行
   ├ 媒体月次 … 月×媒体の表示回数・クリック数・応募数・費用
   └ 選択肢   … プルダウンの元
        ↓ Googleログイン（nex-gate.jp）して Sheets API で読む
index.html（GitHub Pages）
```

バックエンドなし。index.html 1枚と Chart.js だけ。

## 入力のルール（応募者タブ）

| 列 | 入れるもの |
|---|---|
| 応募日 | 必須。これが無い行は集計に入らない |
| 候補者名 | 表示用 |
| 職種 | 自由入力（現場職 / 事務 など）。絞り込みに使う |
| 雇用形態 | プルダウン |
| 応募経路 | プルダウン（Indeed / Airワーク / ハローワーク…） |
| ステータス | プルダウン。番号で段階を表す（下記） |
| 書類通過日 / 面接日 / 内定日 / 入社日 | 分かる範囲で。ステータスより優先して段階判定に使う |
| メモ | 自由 |

### ステータスの読み方

- 8.書類選考 → 7.面接調整中 → 6.面接済（結果待ち） → 5.内定（返答待ち） → 2.内定承諾（入社待ち） → 1.入社済み
- 9.x は離脱（9.1 書類で企業断り / 9.2 面接前に連絡不通 / 9.3 面接で企業断り / 9.4 面接後に連絡不通 / 9.5 面接後辞退 / 9.6 内定辞退 / 9.7 入社辞退 / 9.8 早期退職）
- ファネルの「書類通過」は 7 以降と 9.2〜9.8、「面接実施」は 6 以降と 9.4〜9.8、「内定」は 5 以降と 9.6〜9.8、「入社」は 1 と 9.8 を数える

### 媒体月次タブ

Indeed の管理画面の数字を月ごとに写す。表示回数・クリック数・応募数・費用を入れると、クリック率・応募率・応募単価が出る。クリック率3%未満は赤で出る。

## 会社を増やす

1. 既存のスプレッドシートを「コピーを作成」して会社名に変える（タブ構成とプルダウンがそのまま付いてくる）
2. 共有が「nex-gate.jp のユーザー → 閲覧者」になっていることを確認する（フォルダ内にコピーすれば引き継がれる）
3. `index.html` の `CONFIG.companies` に1行足す（`sheetId` はURLの `/d/` と `/edit` の間）
4. push すると数十秒で反映

## 公開範囲（社内限定）

- シートと Drive フォルダは「nex-gate.jp のユーザーが閲覧可」。顧問など社外アドレスからは見えない
- 画面は Google ログイン方式。`CONFIG.oauthClientId` にウェブ用OAuthクライアントIDを入れると有効になる（空のままだと公開CSV方式で、社内限定シートは読めない）
- OAuth同意画面を「内部」にしておくと、nex-gate.jp 以外のアカウントはそもそもログインできない
- ログインの有効期限は約1時間。切れたら右上の「更新」で再ログイン

## 定例で見せるとき

会社タブの「定例用の画面を開く」か、`?co=会社名&solo=1` のURLを開く。その会社だけが表示され、全社横断と他社のタブは出ない。画面共有はこのURLで行う。
